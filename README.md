# Pixel Arena Widget

Android home-screen widget featuring an autonomous pixel-art battle between Male Hero Template and Skullwolf.

## Build
1. Upload the supplied `PixelArena-Android-Source.zip` to the repository root.
2. Open **Actions → Build Pixel Arena APK**.
3. Download the `PixelArena-debug-apk` artifact from the completed run.

The source archive contains the Gradle Android project under `pixelarena-project/`. The workflow extracts it and builds the debug APK.

## Widget
- Autonomous AI-driven combat; no commands required.
- Randomized action selection with consecutive-action avoidance.
- Arena boundary collision and movement.
- Ice, solid, transparent and glass background modes.
- Resizable Android home-screen widget.
